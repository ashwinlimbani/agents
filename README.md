## 📖 About

As software systems evolve from traditional applications to AI-native experiences, engineers must understand how autonomous agents reason, collaborate, invoke tools, and execute complex workflows.

This repository contains my hands-on exploration of modern Agentic AI frameworks and patterns, including:

- LangGraph
- CrewAI
- AutoGen
- OpenAI Agents SDK
- Model Context Protocol (MCP)
- Tool Calling
- Agent Orchestration
- Multi-Agent Collaboration
- Workflow Automation

The goal is to understand how production-grade AI agents are designed, coordinated, and deployed.

# 🧠 Frameworks Covered

## LangGraph

Graph-based orchestration framework for building stateful AI agents.

### Concepts

- State Management
- Conditional Routing
- Multi-Step Workflows
- Agent Loops
- Human Approval Flows

---

## CrewAI

Role-based multi-agent collaboration framework.

### Concepts

- Agents
- Tasks
- Crews
- Sequential Workflows
- Hierarchical Workflows

---

## AutoGen

Microsoft's framework for multi-agent conversations.

### Concepts

- Conversable Agents
- Assistant Agents
- User Proxy Agents
- Multi-Agent Discussions
- Autonomous Collaboration

---

## OpenAI Agents SDK

OpenAI's modern framework for building agentic systems.

### Concepts

- Agents
- Tools
- Handoffs
- Guardrails
- Structured Outputs

---

## MCP (Model Context Protocol)

Standardized protocol enabling agents to interact with external tools and systems.

### Concepts

- MCP Servers
- MCP Clients
- Tool Discovery
- Context Sharing
- External Integrations
